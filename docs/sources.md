# Sources

Every outside thing this repository draws on, with what was taken. "Idea only" = the concept was re-implemented from
scratch and no text or code was copied. Licenses that only ask for a notice (MIT, Apache-2.0, CC BY, CC0) are
reproduced in `THIRD_PARTY_NOTICES.md` where something was copied. Retrieval dates of the web sources: 2026-10-24; on
2026-10-25 the BlackLine release pages (Sandbox notice, release calendars, 2024 product release), the CMS User Manual
template and its "Link to Us" page, Diátaxis and the two issue logs; on 2026-10-26 the OWASP "CSV Injection" page and the
SQLite pages and the pages of the three tables of values and rules below.

BlackLine is a product name of BlackLine Inc. This repository has no relation to that company.
